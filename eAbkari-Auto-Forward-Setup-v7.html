eAbkari Auto Forward — setup (v7)

One-time setup

  1. Delete any old "Auto Forward" bookmarks (v1–v6) from the bookmarks bar (right-click → Delete).
  2. Press Ctrl + Shift + B so the bookmarks bar is visible.
  3. Drag this green button onto the bookmarks bar:

    Auto Forward v7

Daily use

  1. Log in to eAbkari. Permit/Pass → TP-PL Retail → Act On Application, set dates, click Search.
  2. Click Auto Forward v7 on the bookmarks bar. A panel opens bottom-right.
  3. Only one firm: type a name (e.g. TECHSERV) and check the "match" count. Everything: leave the box empty.
  4. Choose Start from: Bottom or Top, click START, read the popup, click OK.
  5. It shrinks to a small grey counter (forwarded / skipped). Click it to see details, STOP, or Show skipped (with the site's reason). Hide shrinks it again.
  6. When it says Done, press F5 to see the updated list.

Requisitions the site refuses (e.g. "stock unavailable") are skipped and stay in the list. Keyword matches consignee / consignor names only, capital/small letters don't matter. Don't open eAbkari in a second tab while it runs.
